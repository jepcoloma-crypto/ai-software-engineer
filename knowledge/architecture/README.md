# Architecture

## Purpose

This directory stores verified, reusable engineering knowledge about software
architecture: high-level system structure, module and component boundaries,
architecture styles, scalability and reliability considerations, and
documented architecture decisions.

## What Belongs Here

- Verified and accepted architecture guidance that can be reused across tasks.
- Confirmed patterns and decisions with their rationale.

Reusable knowledge must be verified before it is treated as authoritative.

## Promotion Requirements

Research-derived knowledge must be verified against authoritative sources and
explicitly human-approved before it is promoted into this directory. Until
then it stays in `knowledge/research/` and must not be presented as fact.
Promoted knowledge must be accurate and free of fabricated technical guidance.
