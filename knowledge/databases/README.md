# Databases

## Purpose

This directory stores verified, reusable engineering knowledge about relational
data: data modeling, schema design, constraints, keys, indexes, queries,
migrations, transactions, concurrency, and data integrity.

## What Belongs Here

- Verified and accepted database guidance that can be reused across tasks.
- Confirmed patterns and practices for schema, query, and data-integrity work.

Reusable knowledge must be verified before it is treated as authoritative.

## Promotion Requirements

Research-derived knowledge must be verified against authoritative sources and
explicitly human-approved before it is promoted into this directory. Until
then it stays in `knowledge/research/` and must not be presented as fact.
Promoted knowledge must be accurate and free of fabricated technical guidance.
